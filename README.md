# BSIS Anatech — Google Data Studio Interactive Quiz

A single-file HTML5/CSS3/vanilla-JavaScript quiz based on the supplied BSIS Anatech Exam Reviewer: Google Data Studio.

## Contents
- `index.html` — complete quiz application
- `assets/grizzamstudy.gif` — supplied mascot GIF used by the app

## Run
Open `index.html` in a modern browser. No server, database, account, framework, or external dependency is required.

## Quiz coverage
The reviewer contains 44 numbered learning items (items 2–45), so the quiz contains 44 questions. Item 39 is represented by one question covering the Owner's Credentials vs. Viewer's Credentials distinction.

## Features
- One question at a time
- Four randomized answer choices
- Immediate correct/incorrect feedback
- Progress bar
- Results with score, accuracy, and performance message
- Full answer review
- Retake quiz
- Light/dark theme with saved preference
- Responsive mobile/tablet/desktop layout
- Keyboard-focusable buttons and reduced-motion support
